# Action hooks

Generated by `mahout-devtools`. Do not edit by hand; run `composer hooks:generate`.

Every hook name is a `public const` on a `Hooks` class; its `@action` or `@filter` docblock tag decides which of the two documents the entry lands in.
The other kind lives in `filters.md`.

| Constant | Hook | Arguments | Since | Description |
|---|---|---|---|---|
| `BEFORE_BOOT` | `mahout/kernel/before_boot` | `Kernel $kernel` | 1.0 | Fires before the kernel registers providers and modules. |
| `AFTER_BOOT` | `mahout/kernel/after_boot` | `Kernel $kernel` | 1.0 | Fires after every provider and module registered and booted. |
| `BOOT_FAILED` | `mahout/kernel/boot_failed` | `\Throwable $failure`, `Kernel $kernel` | 1.0 | Fires when a provider or a module throws during boot. |
| `ALL` | `all` | `string $hookName` | 1.0 | Core's hook that fires for every action and filter. The development-only hook validator observes it; it is not a mahout hook. |
